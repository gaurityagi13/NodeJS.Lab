## Description

This lab assignment demonstrates the basic working of a Node.js HTTP server.

The server includes:
- A home route `/`
- An `/about` route
- A `/college` route
- A `/profile` route that returns JSON data
- A 404 Page Not Found response
- A configurable PORT using an environment variable
